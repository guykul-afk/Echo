# Execution Log: 18/09/2026 14:18 - Server-Side Epistemic Profile Resilience

- **Category:** Architecture/Cloud
- **Timestamp:** 2026-09-18T11:18:39.026Z

## 1. What Failed / Rework Required
Profile appeared empty on mobile because profile was not stored in Cloud Firestore, /api/user-profile returned HTML SPA fallback, and security rules restricted profile reads.

## 2. Root Cause Analysis & Solution
Stored Guy Kuleski profile in /profiles/Guy_Kuleski in Firestore, updated firestore.rules, added multi-tier server fetch, and deployed hosting and rules to Firebase.

## 3. Persistent Lesson Learned
Strict server-only profiles must be pre-calculated and stored in Cloud Firestore and Hosting CDN, with public read rules and a 4-tier server fetch pipeline.
